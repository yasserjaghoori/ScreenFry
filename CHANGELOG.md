# ScreenFry changes

What's new in each version. The Mac app's update window shows the section for the version it
offers, and each GitHub release uses it as its notes, so keep entries short and in plain words.
Add changes under "Unreleased"; a release turns that heading into its version
(see docs/DISTRIBUTION.md).

## Unreleased

- Two ScreenFrys in the download: **ScreenFry** adds Chrome's extension from the Chrome Web Store (one click, updated by Chrome, no Developer mode), and the greyed **ScreenFry Developer** keeps the Developer mode version. Safari is the same in both.
- Using ScreenFry in Chrome's Developer mode? It keeps working and updating. The Chrome card explains moving to the Web Store version with your setup.
- Erase Everything now erases both Chrome versions when both are installed.
- ScreenFry is on the Mac App Store too, with the same Safari extension, Chrome from the Chrome Web Store, and updates through the App Store.

## 1.0.0

ScreenFry 1.0: less feed, more day, in Safari and Chrome.

- Hide feeds, recommendations and buttons on YouTube, Instagram, X, Reddit, Substack, TikTok, Facebook, LinkedIn and Quora, while search, links and messages keep working.
- Block Shorts and Reels, or let only the one you were sent play (research mode).
- Daily limits, allow and block windows, and Fry Time windows that open feeds up for a while.
- Earn your time on websites you want to use more, and share your setup with a code.
- The Mac app sets up both browsers, keeps five loadouts for all of them, and updates itself.
- A clearer README and privacy page.

## 0.8.2

- Update and Check for Updates always respond now: they install an update that's already downloaded, or open the update window with what's new and a download bar.
- Updates always fetch the newest version, so you go straight from an old version to the latest in one update.
- Automatic updates wait while ScreenFry's window is open, so it never restarts while you're using it, and install as soon as you close it.
- The update window shows what's new in the version it offers.
- The menu bar menu has What's New, which opens this version's changes.

## 0.8.1

- Restart Chrome button in the Mac app while Chrome finishes a ScreenFry update. It warns before Chrome closes its tabs.

## 0.8.0

- Fry Time shows as a small dripping timer beside each website, in the dashboard and the popup.
- Loadouts can be renamed in the browsers and the Mac app.
- Chrome's status says to open or restart Chrome to finish an update.

## 0.7.9

- Automatic updates install right away instead of waiting for ScreenFry to quit.

## 0.7.8

- Menu bar icon in ScreenFry's silhouette. It turns orange with an Update item when a new version is ready.
- The welcome page's button works again after Chrome reloads ScreenFry.
- Fixed a crash when Chrome closed its connection to the Mac app mid check-in.
