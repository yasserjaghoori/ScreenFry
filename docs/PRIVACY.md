# Privacy

Screentime has no account, backend, advertising, telemetry, or analytics. Rules, browsing-duration counters, feed preferences, and override history use extension-local storage. The extension requests host access because it must match and enforce user-created website rules; it does not collect page text or form values.

Export is intentionally not represented as a cloud sync feature. Browser-local data may be removed by uninstalling the extension or deleting its site data. During a live commitment, the product UI does not offer deletion that would erase the commitment; browser-level deletion cannot be prevented by an extension.
